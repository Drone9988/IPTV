# 📺 Free IPTV Aggregator & Stream Health Validator (GitHub + Cloudflare)

An automated, self-healing **Free IPTV** aggregator powered by **GitHub Actions** and **Cloudflare Workers / Pages**.

It automatically aggregates thousands of free, legal, and public broadcast channels worldwide, continuously validates every stream's health, eliminates broken/offline links, captures updated stream endpoints when broadcasters change their CDN URLs, and delivers lightning-fast playlists via Cloudflare's global edge network.

---

## 🌟 Key Features

- 🔄 **Self-Healing & Auto-Updating**: A GitHub Actions cron workflow runs every 6 hours to test every stream. If a stream URL changes, redirects, or goes offline, it automatically updates or removes it.
- ⚡ **Cloudflare Edge CDN**: Cloudflare Worker caches and routes playlists with sub-30ms global response times and eliminates GitHub rate limits.
- 🎯 **Dynamic Filtering**:
  - Filter by category on the fly: `/playlist.m3u8?category=news`, `sports`, `movies`, `music`, etc.
  - Filter by country on the fly: `/playlist.m3u8?country=us`, `uk`, `ca`, etc.
  - Search any channel dynamically: `/playlist.m3u8?search=bbc`
- 🛡️ **Built-in CORS & Stream Proxy**: Includes an edge streaming proxy (`/proxy?url=...`) to play streams in browsers and clients that enforce CORS or strict referrer headers.
- 🖥️ **Turnkey Web TV Player**: Beautiful, responsive web player built with Tailwind CSS and HLS.js. Ready to deploy in 1 click to Cloudflare Pages or GitHub Pages.
- 📱 **Universal Compatibility**: Works out of the box with VLC, TiviMate, IPTV Smarters, Kodi, Apple TV, Android TV, and Fire TV Stick.

## 🚀 Quick Setup & Deployment Guide

### Step 1: Push This Project to GitHub

1. Initialize git and commit your files:
   ```bash
   git init
   git add .
   git commit -m "Initial commit of Free IPTV aggregator"
   ```
2. Create a new repository on [GitHub](https://github.com/new) (e.g. `Free-IPTV`).
3. Push to your GitHub repository:
   ```bash
   git remote add origin https://github.com/<YOUR_USERNAME>/<YOUR_REPO>.git
   git branch -M main
   git push -u origin main
   ```

### Step 2: Enable GitHub Actions Workflow

1. Go to your GitHub repository and click the **Actions** tab.
2. Under "Workflows", select **Automated IPTV Stream Health Checker & Updater**.
3. Click **Run workflow** &rarr; **Run workflow** to trigger the initial stream scan immediately.
4. Thereafter, GitHub Actions will automatically re-run every 6 hours (`0 */6 * * *`) without any manual intervention!

> [!TIP]
> Ensure GitHub Actions has write permissions: In your repository, go to **Settings** &rarr; **Actions** &rarr; **General** &rarr; **Workflow permissions** &rarr; select **Read and write permissions** &rarr; click **Save**.

---

### Step 3: Deploy to Cloudflare

You have two options for Cloudflare:

#### Option A: Cloudflare Pages (Instant Web Player & Static Playlists)
1. Go to [Cloudflare Dashboard](https://dash.cloudflare.com/) &rarr; **Workers & Pages** &rarr; **Create application** &rarr; **Pages** &rarr; **Connect to Git**.
2. Select your GitHub repository.
3. Configure build settings:
   - **Framework preset**: `None`
   - **Build output directory**: `public`
4. Click **Save and Deploy**. Your web player is now live at `https://<project-name>.pages.dev`!

#### Option B: Cloudflare Worker (Dynamic Filtering & Edge Caching)
1. In `worker/wrangler.toml` and `worker/index.js`, update the `UPSTREAM_URL` with your GitHub username:
   ```toml
   UPSTREAM_URL = "https://raw.githubusercontent.com/<YOUR_USERNAME>/<YOUR_REPO>/main/public/streams"
   ```
2. Deploy using Wrangler CLI:
   ```bash
   cd worker
   npx wrangler deploy
   ```
   *Or paste `worker/index.js` directly into the Cloudflare Worker web editor in your browser!*

## 📡 Using Your Playlists in IPTV Apps

Once deployed, copy your M3U link into any media player or IPTV app:

| Media Player / App | How to Add Playlist |
| :--- | :--- |
| **VLC Media Player** | `Media` &rarr; `Open Network Stream` &rarr; Paste `https://<your-worker>.workers.dev/playlist.m3u8` |
| **TiviMate (Android TV / Firestick)** | `Add Playlist` &rarr; `M3U Playlist` &rarr; Enter playlist URL |
| **IPTV Smarters Pro** | `Load Your Playlist or File/URL` &rarr; Enter URL |
| **Kodi** | `Add-ons` &rarr; `PVR IPTV Simple Client` &rarr; Configure M3U URL |
| **Apple TV / iOS (IPTVX, GSE)** | `Add Playlist` &rarr; `Remote Playlist` &rarr; Enter URL |

### Dynamic Filtering URLs
- **All Channels**: `https://<your-worker>.workers.dev/playlist.m3u8`
- **News Only**: `https://<your-worker>.workers.dev/playlist.m3u8?category=news`
- **Sports Only**: `https://<your-worker>.workers.dev/playlist.m3u8?category=sports`
- **United States Only**: `https://<your-worker>.workers.dev/playlist.m3u8?country=us`
- **United Kingdom Only**: `https://<your-worker>.workers.dev/playlist.m3u8?country=uk`

## ⚙️ Customization

To add your own favorite sources or change validation behavior, simply edit `src/config.py`:
- **`SOURCES`**: Add new M3U URLs (e.g. your local TV feeds, Pluto TV, Samsung TV Plus).
- **`CHECKER_SETTINGS['concurrency']`**: Adjust how many streams are tested simultaneously (default: 40).
- **`CHECKER_SETTINGS['timeout_seconds']`**: Adjust timeout per stream (default: 6 seconds).
- **`CHECKER_SETTINGS['filter_adult']`**: Automatically exclude adult/NSFW content (`True`).
